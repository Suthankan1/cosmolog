Dependencies: baseline and previous release gate; reviewed source references S01–S06/S13. Goal: engaging local scientific interaction, not another API dashboard.

- [x] 1.3.1 Review the reference-data seeds in docs/expansion and actual existing catalog. Build a versioned minimal dataset with source refs, quantity/unit, precision and distance definition. Reuse HYG distances only when present/licensed, preserve attribution; no invented data.

## F04 — Cosmic Scale Laboratory
- [x] 1.3.4 Validate a small diameter dataset with consistent reference convention, separate mean orbit distance and current geocentric distance. Add ratio/travel math pure helpers; positive finite speed, travel speed below c; no fake real trajectory or implied spacecraft capability. Unit tests for invalid speed, identical body, units, schematic scale and precision.
- [x] 1.3.5 Add diameter comparison, distance comparison and hypothetical travel time screen with consistent shared scale per mode; labels for logarithmic/schematic views, presets, accessible text table. Use React Native primitives initially; add SVG only after demonstrated need and native SDK compatibility. No new astronomy engine.
