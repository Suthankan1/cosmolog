# Task 00 — Repository and design foundation

## Goal
Create a clean Expo + React Native + TypeScript foundation without implementing business features.

## Read first
- `AGENTS.md`
- `PROJECT_CONTEXT.md`
- `docs/ASSIGNMENT_REQUIREMENTS.md`
- `design/DESIGN_SYSTEM.md`
- `design/SCREEN_SPECIFICATIONS.md`

## Steps
1. Review Figma screens and record visual corrections.
2. Verify current Expo stable SDK and create project.
3. Enable TypeScript strictness appropriate to Expo template.
4. Configure ESLint and formatting.
5. Add route skeleton only (auth group, tabs, details).
6. Add theme token files aligned with Figma.
7. Add Feather icon wrapper using the required Feather icon package.
8. Add Jest/jest-expo baseline.
9. Confirm Android device/emulator run.
10. Commit foundation separately.

## Acceptance
- App boots on Android.
- TypeScript check and lint pass.
- Navigation placeholders compile.
- No API/database/auth feature has been prematurely implemented.
- Theme token names match design docs.
