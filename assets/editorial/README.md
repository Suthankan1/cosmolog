The Figma v2 artwork uses illustrative high-resolution Figma-generated astronomy imagery. Do not treat it as genuine NASA photography or bundle it into the production app as NASA content. Production cards must use actual attributed API media, with explicit persistent offline image storage for favourites where promised. Original visual references live in `design/references/`.

## Production masthead

`earthrise.jpg` is NASA photograph AS08-14-2383, taken by Bill Anders during Apollo 8 on 24 December 1968. It is bundled so the masthead works without a network connection. Credit: NASA / Bill Anders.

- [NASA Science source and caption](https://science.nasa.gov/resource/apollo-8s-iconic-earthrise/)
- [NASA media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/)

## Launch globe

`blue-marble.png` is a 512 px transparent cutout from NASA photograph AS17-148-22727, taken by the Apollo 17 crew on 7 December 1972. The edit isolates the planetary disk for the forest splash background. Credit: NASA / Apollo 17 crew. [Original photograph and caption](https://www.nasa.gov/image-article/blue-marble-view-from-apollo-17/)
