# Design and product review checklist

Before implementation:
- [ ] Review Figma brand board and logo mark at 24 px, 48 px and 1024 px.
- [ ] Confirm wordmark spacing and tagline legibility.
- [ ] Verify palette contrast for all actual text/background pairs.
- [ ] Check mobile screen frames at 320, 360, 390 and 430 dp widths.
- [ ] Check long title/body wrapping and screen scrolling.
- [ ] Confirm safe areas and bottom navigation placement.
- [ ] Review Login validation/error/loading states.
- [ ] Review offline-first empty-cache vs stale-cache behaviour.
- [ ] Confirm Details route uses only source and item ID.
- [ ] Test screen-reader names and dynamic type.
- [ ] Conduct cognitive walkthrough: sign in, discover, open, save, restart offline, reopen.
- [ ] Ask at least 2–3 representative students to perform the core task and record issues.
- [ ] Update `docs/DECISIONS.md` if review changes a design/technical decision.
