# Project package manifest

This archive is intended to be the root folder opened in Claude, Codex, Antigravity, Copilot or Cursor.

- `AGENTS.md`: canonical shared agent rules.
- `CLAUDE.md`, `GEMINI.md`, `.github/copilot-instructions.md`, `.cursor/rules/cosmolog.mdc`, `.antigravity/rules.md`: assistant-specific entry rules.
- `agents/`: short per-agent entry files.
- `PROJECT_CONTEXT.md`: product and architecture source of truth.
- `docs/`: requirements, architecture, data model, decisions, tests, lecture coverage, progress and submission docs.
- `design/`: design system, screen specs, user flows, Figma link and data model.
- `tasks/`: ordered implementation tasks.
- `assets/brand/`: SVG mark, lockup and launcher icon sources.
- `source_materials/`: original assignment brief and six lecture PDFs.
- `src/`, `tests/`: intentional placeholders; app implementation not started.

Do not treat this package as a completed application. The Figma design and project context are prepared; the student should review them before the first code slice.
